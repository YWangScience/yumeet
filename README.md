# yuMeet 设计规格包

用最新理念设计、替代 CERN Indico 的开源会议/活动管理系统 **yuMeet** 的完整设计文档与执行计划。

## 文件结构

- **[PLAN.md](PLAN.md)** — 给编码智能体(AI coding agent)的执行入口:架构不可变更项、模块→章节映射、实现顺序、里程碑与验收标准。**从这里开始。**
- **docs/ch01.md – ch14.md** — 14 章完整设计规格(字段级 schema、API 示例、视觉 token、部署清单):

| 章 | 内容 |
| --- | --- |
| ch01 | 设计哲学与产品定位(八大原则、复杂度分配) |
| ch02 | 总体架构与技术选型(Next.js 全栈 + Fastify 开放边界 + 共享内核) |
| ch03 | 角色模型与信息架构(五角色、关键旅程、URL 方案) |
| ch04 | 核心功能 I:活动创建、注册票务、征稿评审、邮件 |
| ch05 | 核心功能 II:日程编排、现场、归档、通知与状态追踪 |
| ch06 | 身份、账户与权限(passkey/magic link、能力矩阵) |
| ch07 | 模板与主题系统(四层自定义、Cupertino 主题规范) |
| ch08 | 设计系统与交互规范(动效、⌘K、Mac 原生感、无障碍) |
| ch09 | 数据模型(Drizzle schema、状态机、字段引擎)— 状态机与审计表的唯一事实源 |
| ch10 | API 与开放集成(/api/v1、webhooks、ICS/JSON-LD、嵌入套件 Embed Kit)— 事件名的唯一事实源 |
| ch11 | 配置与部署(配置分层、docker compose、CLI) |
| ch12 | 安全、隐私与合规(威胁模型、保留期权威表、审计) |
| ch13 | 性能、可靠性与扩展(性能预算、抢票、插件、规则引擎) |
| ch14 | 迁移、路线图与开源策略(Indico 迁移器、M1→M3) |

## 用法

在本目录启动你的编码智能体,让它读取 `PLAN.md` 并按里程碑执行,例如:

```text
请阅读 PLAN.md,按 M0 → M1 的顺序开始实现,每个模块动工前先读映射表指向的章节。
```
