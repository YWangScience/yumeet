# 第 8 章 · 设计系统与交互规范

本章定义 Cupertino UI 组件库之下的完整设计系统:排版、色彩、材质、动效四套 token,组件规范清单,以及「在 Mac 上像系统自带应用」这一硬约束的逐项落地(⌘K 命令面板、快捷键、聚焦环、PWA、触控板行为、右键菜单)。所有数值以第 7 章 Cupertino 主题基准为默认值,本章给出的是这些数值背后的规则系统——换主题时规则不变,只换 token 值。无障碍与中文排版作为工程验收项而非附录写入本章末尾。

## 8.1 排版与字体栈

排版系统的第一原则:不下载任何字体文件。字体栈完全依赖系统字体,在 macOS/iOS 上命中 SF Pro 与 PingFang SC,在 Windows 上命中显式列出的 Segoe UI 与微软雅黑,零网络请求、零 FOUT/FOIT,LCP 不为字体买单(性能预算见第 13 章)。代码与数字场景使用等宽栈,命中 SF Mono / Menlo。

```css
:root {
  --yu-font-family-base: system-ui, -apple-system, "SF Pro Text", "Segoe UI",
                         "Helvetica Neue", "PingFang SC", "Microsoft YaHei", sans-serif;
  --yu-font-family-mono: ui-monospace, "SF Mono", Menlo, Consolas,
                         "PingFang SC", monospace;
}
body {
  font-family: var(--yu-font-family-base);
  font-size: 17px;
  line-height: 1.6;
  -webkit-font-smoothing: antialiased;
}
```

字号不允许在组件里写死,只允许引用语义角色 token。角色 token 即第 7 章 7.4.1 的 `--yu-text-*` 字阶——本表是其常用子集的引用,数值与 7.4.1 完全一致,不另设一套(完整 11 级含 display-2、title-3、body-large,见第 7 章);负字距只施加于 40px 及以上的西文标题,中文标题降级规则见 8.8:

| 角色 token | 默认值(桌面) | 行高 | 字距 | 用途 |
| --- | --- | --- | --- | --- |
| --yu-text-display-1 | 80px / 600 | 1.05 | -0.015em | 活动首页 hero 主标题 |
| --yu-text-title-1 | 48px / 600 | 1.08 | -0.008em | 页面主标题 |
| --yu-text-title-2 | 40px / 600 | 1.10 | -0.005em | 分区标题 |
| --yu-text-headline | 21px / 600 | 1.30 | +0.011em | 卡片标题、日程场次名 |
| --yu-text-body | 17px / 400 | 1.60 | -0.022em | 正文、表单 |
| --yu-text-callout | 15px / 400 | 1.45 | -0.016em | 表单标签、次要正文 |
| --yu-text-footnote | 14px / 400 | 1.42 | -0.012em | 元信息、时间戳、徽标文字 |
| --yu-text-caption | 12px / 400 | 1.35 | 0 | 图注、法务文字、全大写小标签 |

数字排版两条硬规则:所有表格、金额、倒计时、统计数字必须开启 `font-variant-numeric: tabular-nums`,避免刷新时抖动;订单号、票号、API key 用 `--yu-font-family-mono` 呈现并支持一键复制。

## 8.2 色彩系统

色彩只有一份语义 token 表——即第 7 章 7.4.2 的 `--yu-color-*` 色板,本表数值即第 7 章 token 的引用,不另设一套。浅/深两列值,组件永远引用语义名而非色值。实现方式:`:root` 定义浅色,`[data-theme="dark"]` 与 `prefers-color-scheme: dark` 覆写(三态主题的 CSS 结构见第 7 章)。语义色分「填充值」与「文字值」两档——鲜亮填充色直接作正文文字大多不达 4.5:1 对比度,必须用加深的文字变体。

| token | 浅色 | 深色 | 用途与约束 |
| --- | --- | --- | --- |
| --yu-color-bg-page | #ffffff | #000000 | 页面底色 |
| --yu-color-bg-section | #f5f5f7 | #161617 | 分区底、管理后台画布 |
| --yu-color-bg-elevated | #ffffff | #1d1d1f | 卡片、弹层;深色下靠提亮而非阴影区分层级 |
| --yu-color-text-primary | #1d1d1f | #f5f5f7 | 正文 |
| --yu-color-text-secondary | #6e6e73 | #86868b | 次要文字;对白/黑底对比度 5.1:1 与 5.8:1,达 AA |
| --yu-color-hairline | #d2d2d7 | rgba(255,255,255,0.16) | 发丝线,1px,不得加粗 |
| --yu-color-accent | #0071e3 | #2997ff | 链接、主按钮;对底色对比 4.7:1 / 7.0:1 |
| --yu-color-accent-hover | #0077ed | #4dabff | 仅 hover 态 |
| --yu-color-success / -success-text | #34c759 / #248a3d | #30d158 / #30d158 | 填充/文字两档;「已录用」「已签到」 |
| --yu-color-warning / -warning-text | #ff9500 / #c93400 | #ff9f0a / #ff9f0a | 「候补中」「等待付款」 |
| --yu-color-danger / -danger-text | #ff3b30 / #d70015 | #ff453a / #ff453a | 「已拒绝」、破坏性按钮 |
| --yu-color-focus-ring | #0071e3 | #2997ff | 聚焦环,不透明实色,对相邻底色 ≥3:1(WCAG 1.4.11),见 8.6 |
| --yu-color-focus-ring-soft | rgba(0,113,227,0.18) | rgba(41,151,255,0.22) | 半透明,仅输入框聚焦内圈,见 8.6.3 |

> **设计要点** 状态色的语义在全系统唯一:绿=终态成功、橙=等待中间态、红=终态失败、蓝=可操作。注册状态机(第 9 章)的每个状态在 UI 层映射到且仅映射到一个语义色,禁止组件各自发明颜色;色彩不作为唯一信息通道,始终伴随文字标签(WCAG 1.4.1)。

## 8.3 材质与层级

层级不用 z-index 数字大战表达,而是四级材质,每级绑定固定的背景、阴影与圆角。阴影刻意克制——浅色模式阴影极淡,主要靠发丝线与底色差分层;深色模式阴影几乎不可见,靠 `--yu-color-bg-elevated` 提亮分层。

| 层级 | 圆角 | 阴影(浅色) | 典型组件 |
| --- | --- | --- | --- |
| 0 平面 | 0 | 无,发丝线分隔 | 页面分区、表格 |
| 1 卡片 | 18px | 0 2px 8px rgba(0,0,0,0.04) | Card、活动卡、统计卡 |
| 2 浮层 | 12px | 0 8px 32px rgba(0,0,0,0.12) | Popover、Dropdown、Tooltip |
| 3 模态 | 18px | 0 24px 64px rgba(0,0,0,0.22) | Dialog、Sheet、⌘K 面板 |

毛玻璃材质只允许出现在三处:顶部导航、⌘K 面板背景、移动端底部操作条。统一为一个工具类,并为不支持 backdrop-filter 的环境提供不透明兜底:

```css
.material-glass {
  background: rgba(251, 251, 253, 0.8);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  backdrop-filter: blur(20px) saturate(180%);
}
/* 深色分支:显式选择的深色,以及「跟随系统」时的系统深色 */
[data-theme="dark"] .material-glass { background: rgba(22, 22, 23, 0.72); }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) .material-glass { background: rgba(22, 22, 23, 0.72); }
}
/* 兜底:两种前缀均不支持时退为不透明底 */
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .material-glass { background: rgba(251, 251, 253, 0.97); }
  [data-theme="dark"] .material-glass { background: rgba(22, 22, 23, 0.97); }
  @media (prefers-color-scheme: dark) {
    :root:not([data-theme="light"]) .material-glass { background: rgba(22, 22, 23, 0.97); }
  }
}
```

控件圆角取 8–12px 区间的两档:紧凑控件(输入框、次按钮、标签)8px,常规控件(主按钮、分段控件)12px;胶囊按钮用 999px。同一行内的控件必须同档圆角。

## 8.4 动效规范

动效实现分两层:纯状态过渡(hover、颜色、透明度)用 CSS transition;带物理感的入场/出场/重排用 Motion 的 spring。三条硬规则:只动画 `transform` 与 `opacity`,布局变化一律走 FLIP(Motion 的 layout 动画);出场时长为入场的 0.75 倍,曲线反转;任何动效不得阻塞交互——用户在动画中途点击,动画立即让位。全部参数收敛为下表的具名 preset,组件代码禁止出现裸数字:

| preset 名 | 时长 / spring 参数 | 曲线 | 适用场景 |
| --- | --- | --- | --- |
| fade-fast | 120ms | ease-out | hover 颜色与透明度、图标切换 |
| fade-base | 200ms | cubic-bezier(0.25, 1, 0.5, 1) | Tooltip、Skeleton 到内容的交接 |
| slide-page | 320ms | cubic-bezier(0.25, 1, 0.5, 1) | 向导步骤切换、Tabs 内容平移 |
| spring-snappy | stiffness 500, damping 35, mass 1 | Motion spring | Switch 拨杆、SegmentedControl 滑块、按钮按压 scale(0.97) |
| spring-default | stiffness 320, damping 28, mass 1 | Motion spring | Popover/Dropdown/⌘K 入场:opacity 0→1 + scale 0.96→1,transform-origin 对齐触发点 |
| spring-gentle | stiffness 180, damping 24, mass 1 | Motion spring | Dialog 居中浮现、Sheet 自底部滑入、Drawer |
| spring-bouncy | stiffness 400, damping 18, mass 1 | Motion spring | 签到成功对勾、Toast 入场、状态追踪节点点亮(第 5 章) |
| layout-reorder | stiffness 350, damping 30, mass 1 | Motion layout(FLIP) | 日程块拖拽落位、列表增删重排、看板卡片移动 |

CSS 侧同名导出为自定义属性(`--yu-motion-duration-fast: 120ms` 等)。spring preset 的 CSS 落地采用三级回退链:`spring()` 时间函数(尚无稳定浏览器实现,作为未来路径预留)→ `linear()`(现在的主路径:构建时为每个 spring preset 预生成逼近折线,Motion 官方做法)→ `cubic-bezier()`(老浏览器兜底)。

**prefers-reduced-motion 降级规则**(全局强制,组件不得自行豁免):

1. 所有位移/缩放类入场出场(spring-default、spring-gentle、slide-page)降级为 80ms 纯 opacity 淡入淡出;transform 一律清零。
2. spring-bouncy 类庆祝性动效直接跳到终帧,静态显示结果(对勾直接出现)。
3. FLIP 重排动画关闭,元素瞬移到新位置;拖拽过程中的跟手位移保留(那是直接操纵,不是装饰动效)。
4. Skeleton 的 shimmer 扫光停为静态灰块;一切自动播放的视差、滚动驱动动画、marquee 完全禁用。
5. `scroll-behavior: smooth` 降为 auto,锚点与「回到顶部」瞬时跳转。
6. 信息性动画保留但简化:加载 spinner、进度指示这类传达状态的动画标注 `data-motion="essential"`,作为全局冻结的逃生口继续播放;SSE 公告仍然更新内容但不做滑入,配合 aria-live 播报(见 8.7)。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 80ms !important;
    transition-property: opacity, color, background-color !important;
    scroll-behavior: auto !important;
  }
  /* 逃生口:传达状态的信息性动画(spinner、进度指示)不冻结 */
  [data-motion="essential"],
  [data-motion="essential"]::before,
  [data-motion="essential"]::after {
    animation-duration: revert !important;
  }
}
```

JS 侧统一经 Cupertino UI 导出的 `useMotionSafe()` hook 读取该偏好,Motion 组件据此把 spring preset 替换为 `{ duration: 0.08 }`。

## 8.6 Mac 原生感清单

「像系统自带应用」被拆解为六个可验收的工程项。所有能力做平台探测:macOS 显示 ⌘/⌥/⇧ 符号,其余平台显示 Ctrl/Alt/Shift 并等价绑定。

### 8.6.1 ⌘K 命令面板

**唤起与关闭:**全局 ⌘K(Windows/Linux 为 Ctrl+K)在任何页面唤起,包括焦点在输入框内时(⌘K 与 ⌘S/⌘Enter/Esc 同属穿透输入框的白名单,见 8.6.2,其中 ⌘K 是唯一全局唤起类组合键);导航栏搜索按钮点击等价唤起;打开状态再按 ⌘K 或 Esc 关闭;查询非空时第一次 Esc 清空查询、第二次关闭。面板为层级 3 模态,宽 640px,顶部对齐视口 20% 处,背景遮罩 rgba(0,0,0,0.3),面板本体用 material-glass。

**搜索范围按角色分屏**(与第 3 章角色模型一致):公共活动站内,范围 = 本活动的页面、日程 session、讲者、以及「我的注册」相关动作;管理后台内,范围 = 导航目的地、管理命令、实体检索(注册记录、投稿、订单、邮件模板)、最近访问。实体检索走 API 侧 Postgres FTS(第 13 章),防抖 150ms;导航与命令用客户端预建索引,首字符响应预算 50ms。中文支持拼音全拼与首字母匹配(「zcsp」命中「注册审批」)。

| 动作类型 | 行为 | 示例 |
| --- | --- | --- |
| navigation | Enter 跳转,⌘Enter 新标签页打开 | 「注册管理」「日程编排器」 |
| command | 立即执行;破坏性命令(红字标注)Enter 后仍弹确认 Dialog,绝不直接执行 | 「发布日程」「导出参会名单 CSV」 |
| create | 打开对应创建表单,支持带参 | 「新建活动」「新建邮件模板」 |
| entity | 服务端检索结果,带类型徽标与状态色点 | 键入姓名命中某条注册记录 |
| sub-page | Enter 或 Tab 进入二级列表,面包屑显示于输入框前,空查询时 Backspace 返回上级 | 「切换活动…」→ 活动列表 |
| recent | 空查询时默认展示,最多 5 条 | 最近打开的活动与页面 |

结果按类型分组,组内最多 8 条;↑↓ 移动、Enter 执行;所有条目右侧显示其全局快捷键(若有),面板因此兼任快捷键教学入口。

### 8.6.3 聚焦环

聚焦环只在 `:focus-visible` 时出现——鼠标点击不出环,键盘 Tab 必出环。样式为全局唯一,组件禁止自定义:

```css
:focus-visible {
  /* 不透明实色,浅 #0071e3 / 深 #2997ff,对相邻底色 ≥3:1(WCAG 1.4.11) */
  outline: 3px solid var(--yu-color-focus-ring);
  outline-offset: 2px;
}
.input:focus-visible {
  outline: none; /* 输入框改用内圈,避免与边框叠加 */
  border-color: var(--yu-color-accent);
  box-shadow: 0 0 0 4px var(--yu-color-focus-ring-soft); /* 浅 rgba(0,113,227,.18) / 深 rgba(41,151,255,.22),半透明仅此一处 */
}
```

环不得被裁切:任何 `overflow: hidden` 的容器需为聚焦子元素预留 5px 内边距,滚动容器配 `scroll-padding: 8px` 保证被聚焦项完整可见(对应 WCAG 2.4.11)。

### 8.6.4 PWA manifest 要点

1. `display: "standalone"`,`display_override: ["window-controls-overlay", "standalone"]`——安装到 Dock 后无浏览器 chrome,标题栏区域可被顶部导航利用。
2. `id: "/"` 固定应用身份;`start_url: "/?source=pwa"` 用于区分启动来源统计。
3. 图标提供 192/512 两档且含 `purpose: "maskable"` 变体;`theme_color` 写浅色 #ffffff,深色经 HTML 中 `` 补充。
4. `shortcuts` 暴露两个高频入口:「签到台」(/manage/checkin)与「我的日程」(/me/schedule),对应 Dock 图标右键菜单。
5. Service Worker 仅缓存静态资产与已访问的归档页(第 5 章归档),不缓存任何管理后台数据;离线时公共活动页可读,写操作明确报「离线不可用」。

  "start_url": "/?source=pwa",
  "display": "standalone",

### 8.6.5 触控板与滚动行为

1. **绝不劫持滚动。**公共页无 scrolljacking、无强制整屏翻页;视差只允许用 CSS scroll-driven animation 实现且受 reduced-motion 关闭。
2. 模态、抽屉、⌘K 面板内的滚动容器一律 `overscroll-behavior: contain`,防止滚动穿透到页面;页面级保留系统橡皮筋回弹,不做任何模拟。
3. 横向滚动区(日程时间轴、宽表格)支持双指横扫,滚动条用 overlay 式细条(`scrollbar-width: thin`)且仅悬停时着色,永不占布局宽度。
4. 日程编排器:捏合缩放(浏览器投递为 `ctrlKey + wheel`)调节时间刻度,范围每 100px 显示 15 分钟到 2 小时,以指针位置为缩放锚点;⇧+滚轮横向平移;普通滚轮纵向。
5. 锚点跳转设 `scroll-padding-top: 64px`(导航高 + 16px),内容不被毛玻璃导航遮住;吸顶一律用 `position: sticky`,禁止 JS 监听 scroll 改 fixed。
6. 返回手势安全:所有浮层经 History API 入栈,触控板双指左扫(浏览器后退)关闭最上层浮层而非跳离页面。

### 8.6.6 右键菜单范围

自定义右键菜单只出现在「对象上」而非「页面上」:公共站全域保留浏览器原生菜单(参会者复制文字、另存图片的肌肉记忆不可破坏);文本选区上永远原生。管理后台在下列对象表面启用 ContextMenu(Radix),菜单项与行内「…」按钮及 ⌘K 命令严格同源,同一操作三入口一致:

## 8.7 无障碍(WCAG 2.2 AA 落地清单)

> **Indico 的教训** Indico 的无障碍是 20 年后由 GitHub issue 驱动的补课:对比度、键盘陷阱、缺失的表单标签逐个返修,且主题作者可以轻易破坏已修好的部分。yuMeet 把无障碍写进组件库与 CI——组件封装保证语义,axe-core 跑在 Playwright 流水线上,违规即构建失败,主题包只能改 token 不能改语义结构(第 7 章),从机制上防止回退。

页面骨架统一:每页一个 `h1`、landmark 区域(header/nav/main/footer)完整、首个可聚焦元素为「跳到主内容」链接。表单错误处理三件套:错误摘要置顶并可聚焦、逐字段错误文字经 `aria-describedby` 关联、提交失败后焦点移至摘要。SSE 实时公告(第 5 章)渲染进 `aria-live="polite"` 区域,签到成功等即时反馈用 `role="status"`。WCAG 2.2 新增条款逐条对照:

| 条款 | 要求 | yuMeet 落地 |
| --- | --- | --- |
| 1.4.3 / 1.4.11 | 文字 4.5:1、非文字 3:1 | 8.2 全部 token 组合预验证;语义色文字档强制使用 |
| 2.1.1 / 2.1.2 | 全键盘可达、无陷阱 | Radix 焦点管理;Dialog 陷阱 + Esc 逃逸 + 焦点归还 |
| 2.4.7 / 2.4.11 | 焦点可见且不被遮挡 | 8.6.3 全局聚焦环 + scroll-padding 防吸顶遮挡 |
| 2.5.7 拖拽替代 | 拖拽操作有单指针替代 | 日程块右键「移动到轨道/时间…」菜单与键盘方向键移动等价于拖拽 |
| 2.5.8 目标尺寸 | 可点目标不小于 24×24 | 控件最小触达区 24px,移动端 44px;密集表格行内按钮外扩热区 |
| 3.2.6 一致帮助 | 帮助入口位置一致 | 帮助恒在导航末位与 ⌘K「help」组 |

## 8.8 响应式断点与中文/多语言排版

断点沿用 Tailwind v4 默认(内容优先,不为设备型号建断点)。公共活动站正文栏最大 980px、宽内容(日程表)可破格到 1240px;管理后台流式布局,画布上限 1440px,侧边导航在 lg 以下折叠为图标栏、md 以下收入抽屉。

| 断点 | 宽度 | 布局变化 |
| --- | --- | --- |
| (默认) | < 640px | 单列;导航折叠;Dialog 全部降级为底部 Sheet;表格转卡片列表 |
| sm | 640px | 表单双列;卡片网格 2 列 |
| md | 768px | 公共站完整导航;日程表横向多轨出现 |
| lg | 1024px | 管理后台侧边栏展开;卡片网格 3 列 |
| xl / 2xl | 1280 / 1536px | 画布到上限,余量进外边距;编排器显示更多轨道 |

多语言排版按 `html[lang]` 分支,文案层由 ICU MessageFormat 处理复数与性别(第 2 章),视觉层规则如下:

1. 中文标题不吃西文负字距:`:lang(zh)` 下 display/title 级字距归零,body 行高从 1.6 提到 1.7;字阶最重字重全局即 600(第 7 章 7.4.1),恰在 PingFang 真字重范围内,不引入伪加粗。
2. 中西混排开启 `text-autospace: normal` 与 `text-spacing-trim: space-first`(支持的引擎),不支持时不做 JS 补空格——宁可无空格也不引入布局抖动。
3. 换行规则:`:lang(zh)` 用 `line-break: strict` 禁则处理;标题统一 `text-wrap: balance`,正文段落 `text-wrap: pretty`。
4. 日文/韩文经字体栈分支(`:lang(ja)` 落到 Hiragino Sans,`:lang(ko)` 落到 Apple SD Gothic Neo),不与中文共用 PingFang。
5. 全大写样式(caption 角色)仅施加于拉丁字符,CJK 文本跳过 `text-transform`;日期、时区名等由 Intl API 按 locale 格式化,禁止手拼字符串。

```css
:lang(zh) {
  line-height: 1.7;
  line-break: strict;
  text-autospace: normal;
}
:lang(zh) .yu-text-display-1,
:lang(zh) .yu-text-display-2,
:lang(zh) .yu-text-title-1,
:lang(zh) .yu-text-title-2 {
  letter-spacing: 0; /* display/title 级字距归零;字重全局已是 600,无需另降 */
}
```
